# Verified archive walkthrough

`portfolio-archive-demo.gif`, `portfolio-archive-demo.mp4`, and `portfolio-archive-poster.png` are generated by `npm run capture:demo` from the production build pinned in `source-manifest.json`.

The recording shows only checked-in behavior: the archive index, internal project summaries, explicit recovery from a stale hash route, and return to the index. External repositories, research results, live services, and deployments are not exercised or verified.

Run `npm run verify:demo` to check every pinned input, media checksum, decode, dimensions, duration, and frame count.
